IntentCircuit – Sandbox-Escape Detection for AI Coding Agents

Docker and permission allowlists check each action alone, so an allowed file write or an allowed git command can still be used to escape, as in publicly reported 2026 escapes from coding agents. IntentCircuit sits above them and reasons about the agent's intent across actions. It targets indirect escapes, where the agent writes a file the host later runs (.vscode/tasks.json, Git hooks, CI workflows), a gap I did not find covered by existing open-source agent guardrails.
